# ADR 0004: Missing data and evidence
Status: required future scientific contract; not implemented.
Track missing observations explicitly through resampling and feature extraction.
Only comparable valid observations contribute to weighted distance. Report
feature completeness and spatial coverage separately. Minimum evidence thresholds
require documented justification and sensitivity testing, not an arbitrary fixed
percentage. Missing soil mechanics, traction or material data cannot be inferred
from terrain geometry. No scientific measurements are emitted in Phase 1.
