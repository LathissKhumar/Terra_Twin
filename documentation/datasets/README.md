# Dataset status
No datasets acquired or selected in Phase 1. Future selection must verify the
specific official NASA Space Apps challenge resources and authoritative product
documentation. Provider identity alone does not establish challenge eligibility.
Manifests must contain product/version/provider, acquisition URL/date, resolution,
CRS, vertical reference/units, coverage, NoData, processing history, attribution
and checksum. Raw data stays out of Git; no silent substitutions are allowed.
