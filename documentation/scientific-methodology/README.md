# Scientific methodology

ScaleBridge's cross-body spatial harmonization method is documented in
[scale-bridge.md](scale-bridge.md). The deterministic terrain derivatives and
their limits are specified in [terrain-analytics.md](terrain-analytics.md).
Terrain analytics is implemented for validated, metric ScaleBridge rasters.
The configured distribution comparison, evidence gates and clustering behavior
are documented in [analogue-discovery.md](analogue-discovery.md). The current
real-data search produced no eligible candidates because planetary feature
coverage is insufficient. Deterministic mission assessment and evidence
passports are implemented; their interpretation remains constrained by that
coverage gap and by unavailable soil and environmental observations. See the
[Phase 7 report](../validation/phase-7-report.md) and
[Phase 8 integration report](../validation/phase-8-report.md).
